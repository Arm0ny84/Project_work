# Обезличивание CIM RDF/XML

Утилита рассчитана на профиль предоставленной CIM-модели. Она предварительно индексирует имена и ссылки, затем обрабатывает по одному XML-объекту. Проверка повторно вычисляет подстановки и сверяет граф через временную базу SQLite.

## Запуск

Требуется Python 3.10 или новее.

```powershell
python -m pip install lxml Pillow
python anonymize_cim.py input.xml input_anonymized.xml --key-file cim-private.key
python anonymize_cim.py input.xml input_anonymized.xml --key-file cim-private.key --verify
```

При первом запуске скрипт создаёт файл ключа. Повторяемые замены требуют того же ключа и настроек. Итоговая модель записывается в открытом RDF/XML. Для числовых идентификаторов сохраняется число цифр. Атрибуты записываются рядом с тегами, а простые XML-свойства занимают отдельные строки.

Параметр `--coordinates` включает обезличивание координат. При проверке передайте его, если он использовался при преобразовании.

## Настройка языка

По умолчанию используется русский словарь. Чтобы задать другой язык для синтетических значений, передайте `--config path/to/config.json` при преобразовании и проверке. В примере поля `people` содержат имя, фамилию, второе имя, вариант для email и вариант для улицы. Поля `adjectives` задают основную и согласованную форму. Для языков, в которых эти формы совпадают, их можно повторить.

```json
{
  "language": "en",
  "people": [["Jane", "Doe", "Mae", "jane", "Doe"]],
  "adjectives": [["Apple", "Apple"], ["Pear", "Pear"]],
  "class_labels": {"Substation": "Substation", "ТП": "Distribution substation", "Line": "Line"},
  "street_prefix": "Street",
  "number_prefix": "No.",
  "public_hosts": ["example.org"]
}
```

`class_labels` задаёт подписи классов и подтипов. Для собственного языка дополните словари подходящими значениями. `public_hosts` разрешает домашние страницы явно проверенных сторонних доменов. Ссылки на CIM-схемы распознаются отдельно. Другие HTTP-адреса по умолчанию заменяются, так как путь, параметры и имя документа могут раскрыть объект.

## Вложения

Скрипт распознаёт ZIP-пакеты схем, XML, изображения и звук. Текстовые поля схем проверяются по словарю имён и шаблонам. Для изображений проверяются формат, текстовые метаданные и однотонность. Для WAV проверяется отсутствие сигнала. Подтверждённо пустое содержимое перекодируется с удалением метаданных. Для изображений и звука, содержание которых автоматически подтвердить не удалось, используются нейтральные заглушки.

## Проверка файла для сдачи

Имена объектов в описаниях и шаблонах вычисляются по цели RDF-ссылки, когда она однозначна. Служебный код `PSRType.className` сохраняется как классификатор CIM. В Edge файл отображается в стандартном дереве XML. Загрузка из реляционной БД требует отдельной схемы источника. Проверка выполняется на уровне RDF/XML.
